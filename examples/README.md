# BMSUI 示例

这些文件用于验证固件对历史协议和当前功能的兼容性：

- `dashboard_demo.bmsui`：v2 基础控件。
- `status_icons_demo.bmsui`：v2 双状态图片。
- `v3_opacity_demo.bmsui`：v3 透明度和端点。
- `progress_logic_demo.bmsui`：v3 进度比例逻辑。
- `v4_gradient_demo.bmsui`：v4 渐变。
- `v5_vector_shape_demo.bmsui`：v5 `VSHAPE`。
- `v6_font_fidelity_demo.bmsui`：v6 `GLYPHVAL` 字体一致性。
- `v7_image_optimization_demo.bmsui`：v7 图片格式优化与 Base64 资源。
- `gradient_icons_theme.esptheme`：可继续编辑的渐变/图标主题工程。

v1.1.0 Designer 新下发的设备主题默认使用 **BMSUI v7**。固件保留 v1–v6 读取兼容性。
