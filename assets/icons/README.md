# 图标资源包

本目录提供 BMS UI Designer v1.1.0 参考主题使用的透明 PNG 图标，默认尺寸为 64×64，可在 Designer 中作为普通图片或双状态图标自由缩放。

主要图标包括：

- ESP32/芯片：`chip.png`
- 蓝牙：`bluetooth.png`、`bluetooth_on.png`、`bluetooth_off.png`
- 电池/电压：`battery_voltage.png`
- 充电：`battery_charge.png`、`charge_on.png`、`charge_off.png`
- 放电：`battery_discharge.png`、`discharge_on.png`、`discharge_off.png`
- 电流：`current_wave.png`
- 功率：`power_bolt.png`
- MOS 温度：`thermometer.png`
- 剩余容量：`capacity.png`
- 剩余里程：`range_road.png`
- MOS/控制芯片：`mos_chip.png`
- 系统状态：`shield_check.png`、`check_circle.png`、`status_dot.png`
- 时间：`clock.png`
- 双向状态：`transfer.png`
- 菜单：`menu_dots.png`

所有 PNG 均带透明背景，适合直接导入 Designer。主题发送到 ESP32-S3 时透明通道会保留。
