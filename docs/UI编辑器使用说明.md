# UI Designer 使用说明

## 界面布局

Designer 分为四个主要区域：

- 左侧：ESP32 设备部署和文件操作。
- 中左：元素添加和图层管理。
- 中央：320×240 实时画布。
- 右侧：元素属性。

右侧属性区按“基础、位置与尺寸、内容与外观、类型属性”分组。与当前元素无关的选项会自动隐藏，避免属性拥挤和遮挡。

## 添加元素

先选择分类、字段和显示方式，再点击“添加到画布”。

- SOC：动态数值、水平进度、垂直进度、圆环进度。
- 剩余容量：动态数值、水平进度、垂直进度。
- 剩余里程：动态数值、水平进度、垂直进度。
- 电气参数：总电压、电流、功率、总容量、MOS 温度、平均单体电压、单体压差、循环次数。
- 开关/连接：蓝牙连接、充电 MOS、放电 MOS；可选择文字或 ON/OFF 双状态图片。
- 静态元素：文字、图片、矩形、椭圆、圆形。

## 选择与图层

图层越靠上，画布中的显示层级越高。编辑器渲染顺序与图层顺序一致。

- 单击元素：单选。
- 空白处拖动：显示框选矩形，一次选择与框选区域相交的多个元素。
- `Ctrl + 单击`：向当前选择中增加或移除元素。
- `Ctrl + A`：选择画布中全部可见元素。
- 多选后拖动任意已选元素：整组保持相对位置一起移动。
- 多选时右侧单元素属性暂时禁用，避免误把一个元素的属性覆盖到整组；位置调整使用拖动或方向键。
- 图层列表支持 Windows 标准多选，并与画布选择状态同步。

文字和动态数值与图形重叠时，点击文字区域会优先选中文字，避免被下方图形抢占选择。

单选时可上移/下移图层；复制、剪切、快速复制和删除支持多选对象。

## 移动与自由缩放

选中任意元素后会显示 8 个缩放控制点，同时四条边也可以直接拖动。

- 拖动元素内部：移动。
- 拖动左边或右边：只改变宽度。
- 拖动上边或下边：只改变高度。
- 拖动四个角：自由改变宽度和高度。
- 按住 `Shift` 拖动角：保持原宽高比。
- 属性区的 `X / Y / 宽 / 高` 可直接输入精确数值。
- 默认使用 2 px 网格吸附，可在画布下方关闭。
- 方向键：每次移动所选元素 1 px。
- `Shift + 方向键`：每次移动所选元素 5 px。
- 方向键微调不受 2 px 网格吸附限制，便于最终对齐。

以上逻辑适用于静态文字、动态数值、图片、双状态图片、矩形、圆形、椭圆、SOC/剩余容量/剩余里程条形进度和 SOC 圆环。

## 文字

静态文字支持 Windows 系统字体、字号、粗体、对齐、颜色和透明度。双击画布上的静态文字会把编辑焦点切换到文字内容输入框。

静态文字发送到设备前会按所选系统字体转换为透明 A8 字形资源，因此不依赖 ESP32 内置中文字库。只要 Windows 字体本身包含对应字符，中文、英文和常用符号都可以生成到主题中。

动态数值保持实时 BMS 数据绑定，可设置前缀、后缀、字体、颜色、对齐和透明度。

## 图片和透明度

图片支持 PNG/JPG。PNG 自带 Alpha 通道会保留，元素透明度会与图片自身 Alpha 叠加。

蓝牙连接、充电 MOS、放电 MOS 可分别设置开启图和关闭图，设备根据实时状态切换。

所有元素支持 0–100% 透明度：

- 0%：完全透明。
- 100%：完全不透明。

## 几何图形

支持矩形、椭圆和圆形。

矩形支持直角、圆角、倒角、填充颜色、边框颜色和边框宽度。椭圆可独立调整宽高；圆形用于标准圆形元素。

## 进度显示与数据关系

支持进度显示的数据：

- SOC：水平条形、垂直条形、圆环。
- 剩余容量：水平条形、垂直条形。
- 剩余里程：水平条形、垂直条形。

进度比例不是把原始数值直接塞进 0–100：

- SOC：`SOC / 100`。
- 剩余容量：`剩余容量 Ah / 总容量 Ah`。
- 剩余里程：`当前剩余里程 / 满电可用里程`。满电可用里程采用与固件一致的保留容量和 km/Ah 系数，所以它与里程数字本身保持同一逻辑。

条形和圆环都支持直端/圆端。圆环仍只用于 SOC，并可设置环宽、起始角和扫过角。

设备端条形和圆环会先移除 LVGL 默认主题样式，再应用 Designer 中的颜色、圆角、厚度和轨道参数，减少 PC 预览与实机之间的几何差异。

## 文件操作

左侧文件区只保留四个标准操作：

- 新建：创建空白 320×240 画布。
- 打开：打开 `.esptheme` 文件；同时兼容导入旧 `.bmsui` 和 `.json`。
- 保存：第一次保存时选择文件夹和文件名，之后直接覆盖当前 `.esptheme`。
- 另存为：重新选择文件夹和文件名，保存为新的 `.esptheme`。

标题栏显示当前文件名。内容修改后，文件名前会出现 `*`。新建、打开、读取设备 UI 或关闭程序时，如果当前内容尚未保存，会提示“保存 / 不保存 / 取消”。

`.esptheme` 是用户长期保存和继续编辑的工程文件；`.bmsui` 是 Designer 与 ESP32 之间的设备传输格式，正常使用时不需要手工处理。

快捷键：

| 操作 | 快捷键 |
|---|---|
| 新建 | `Ctrl+N` |
| 打开 | `Ctrl+O` |
| 保存 | `Ctrl+S` |
| 另存为 | `Ctrl+Shift+S` |

## 重置画布

“重置画布”只影响电脑中的当前编辑内容：

- 清空所有元素和图层。
- 清除背景图片并恢复默认背景色。
- 保持画布尺寸为 320×240。
- 不修改 ESP32 地址、密码或设备状态。
- 不删除 ESP32 中已经运行的自定义 UI。
- 支持通过撤销恢复重置前的画布。

“重置画布”和“恢复原始 UI”是两个完全不同的操作。后者会删除设备上的自定义 UI，使 ESP32 回到固件内置的 Factory UI。

## ESP32 设备操作

- 检测设备：确认 Designer 与 ESP32-S3 通信正常。
- 读取设备 UI：读取设备当前自定义主题。

如果 ESP32 当前没有连接到有效 BMS，动态数值会显示 `--`，进度条会按 0% 显示；这与主题几何布局无关。连接到有效 BMS 后，动态数值和进度比例才会更新为实时数据。
- 发送 UI：生成主题并发送到设备，成功后显示“UI 已写入设备”。
- 恢复原始 UI：删除自定义主题并重新使用固件内置 Factory UI。

Factory UI 编译在固件中，不能通过 Designer 删除、覆盖或修改。

## 实时画布刷新

实时画布采用离屏双缓冲绘制。只有元素、属性、选择状态或模拟数据发生变化时才请求刷新，不进行周期性强制重绘。拖动、缩放和属性编辑过程中会先在内存缓冲区完成整帧绘制，再一次性提交到窗口，以避免背景擦除和中间帧造成的闪烁。

## 渐变设置

选中 SOC 圆环或进度条后，在右侧“类型属性”中可以设置：

- 渐变：启用或关闭。
- 起始色：使用元素主颜色。
- 终止色：渐变结束颜色。
- 方向：进度条可选自动、横向、纵向；圆环固定沿进度方向渐变。
- 轨道色：未填充区域颜色。

PC 实时画布和 ESP32-S3 使用同一套起始色、终止色和方向设置。

## PNG 图标资源

项目 `assets/icons/` 内提供透明 PNG 图标。可通过“PNG / JPG 图片”导入普通图标，也可将 `*_on.png` 与 `*_off.png` 用于蓝牙、充电 MOS、放电 MOS 的双状态图标。


## 资源占用优化

v1.1.0 会将常用矩形、圆角矩形和正圆自动导出为 BMSUI v5 `VSHAPE`。这类元素直接由 ESP32/LVGL 绘制，不再转换成 RGB565A8 位图。

因此，大面积卡片边框和背景不会再按 `宽 × 高 × 3` 计算运行时资源。图片、双状态图标、系统字体静态文字和复杂位图图形才占用主要运行时资源。设备会根据实际 PSRAM 状态公布资源上限。


## 字体与设备显示一致性

动态数值使用 BMSUI v6 引入、并由当前 v7 继续使用的字形图集。选择系统字体后，Designer 会使用该字体直接生成设备使用的 A8 字形像素。PC 实时画布也使用同一套字形合成方式，因此上传后不会再被替换成 Montserrat。

单位仍以元素右边界为固定锚点。例如 `9.8 V`、`53.20 V`、`123.456 V` 的 `V` 位置不变，数字只向左扩展。温度的 `°C` 同样使用所选系统字体生成，不再依赖固件中文字库。

注意：如果把 `.esptheme` 放到另一台没有安装该字体的 Windows 电脑上重新发送，Windows 可能使用替代字体。为了保持一致，应在发送主题的电脑上安装主题所使用的字体。


## 圆环进度

圆环进度只负责显示 SOC 进度，不再在圆环内部自动绘制数值。需要在圆环中心显示 SOC 时，请单独添加“动态数值”元素并绑定 SOC。这样数值的字体、字号、颜色、透明度和位置可以独立调整。旧主题中的圆环中心值设置会被忽略。


## BMSUI v7 图片优化

发送主题时，Designer 会按最终像素内容自动选择 A8、RGB565 或 RGB565A8，并对重复资源去重。单色图标通常使用 A8，完全不透明图片使用 RGB565，只有需要同时保留彩色和透明度时才使用 RGB565A8。

设备端资源数据使用 `ASSETB64` 传输。Designer 会先读取 `/api/ui/info` 中的运行时资源上限；如果主题超限，会优先提示最大的资源，通常应先缩小这些图片在画布中的实际宽高。
