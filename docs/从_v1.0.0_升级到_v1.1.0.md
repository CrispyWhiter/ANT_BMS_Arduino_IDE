# 从 v1.0.0 升级到 v1.1.0

v1.1.0 是 UI Designer、设备主题协议和动态 UI Runtime 的兼容升级。原有 `v1.0.0` Tag/Release 应保留，不要覆盖。

## 升级步骤

1. 备份 v1.0.0 的 `.esptheme` / `.bmsui` 文件和当前设备配置。
2. 下载 v1.1.0 Release。
3. 使用 Arduino IDE 通过 USB 烧录 v1.1.0 固件一次。
4. 启动 `BMS_UI_Designer_v1.1.0.exe`。
5. 打开旧主题并检查字体、透明度、图片和进度显示。
6. 建议另存为新的 `.esptheme` 工程。
7. 通过设备配置热点发送主题。

## 协议兼容

v1.1.0 Designer 默认生成 **BMSUI v7**。固件继续兼容读取 v1–v6。

- v3：透明资源、静态系统字体和图形。
- v4：进度渐变。
- v5：`VSHAPE` 基础矢量图形。
- v6：`GLYPHVAL` 动态字体字形图集。
- v7：图片格式自动优化、状态蒙版、资源去重和 Base64 资源传输。

## 旧主题迁移

旧 Schema 没有明确透明度字段时，导入后按 100% 不透明处理。当前工程保存时统一规范化到 Theme Version 110 / Schema 8。

圆环进度中的旧中心数值配置不再使用。需要显示 SOC 数字时，应单独添加“动态数值”元素。

动态数值的单位使用固定锚点：单位位置固定，数字长度变化时向左扩展。
